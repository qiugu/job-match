# 文档地图（docs/）

本目录存放项目文档，按「活跃 / 归档」两层组织。唯一活跃路线图是仓库根的 `Plan.md`。

## 层级约定

| 位置              | 内容                                 | 维护状态   |
| ----------------- | ------------------------------------ | ---------- |
| `../Plan.md`      | 唯一活跃路线图（批次、优先级、验收） | 持续更新   |
| `../AGENTS.md`    | 工程约定、环境变量、常用命令         | 持续更新   |
| `docs/`（本目录） | 方案、修复说明、验收记录等活跃文档   | 随功能产出 |
| `docs/archive/`   | 已完成的规划文档，仅作历史留痕       | 不再更新   |

## 新增文档规则

1. 新文档一律放 `docs/` 根目录，文件名用 `PLAN_<主题>.md`（规划）或 `FIX_<主题>.md`（修复/复盘）。
2. 文档完成后不删除：把结论回填 `Plan.md`，文件移入 `docs/archive/` 并在上表登记。
3. 文档内如涉及环境变量或命令变更，同步更新 `AGENTS.md`。
