# DESIGN.md — JDMatch 视觉语言

> **版本** v0.1（评审稿）
> **代号** Paper & Punch（纸张与撞色）
> **状态** 待评审 · 未落地代码
> **适用范围** 落地页、登录/注册、控制台外壳、岗位卡、投递分析、编辑器骨架
> **明确豁免** 简历预览与 PDF 导出（`.resume-preview` / `.resume-markdown-preview`）—— 见 §3.3

---

## 0. 一句话

**把求职这件让人紧张的事，做成一件轻快的事。**

奶油纸做底，硬墨做骨架，撞色做标点。界面有厚度、能被按下、会回弹——像一个可以上手玩的纸玩具，而不是一张被冻结的表单。

---

## 1. 为什么要改

### 1.1 现状诊断

当前仓库里同时存在三套互不相关的视觉语言：

| 区域 | 当前语言 | 问题 |
| --- | --- | --- |
| 落地页 | Newsreader 衬线 + `#F9F9F7` 羊皮纸 + 大圆角柔和阴影 | 偏「文学出版物」，与「AI 工具」的信任感错位；阴影全模糊，缺重力 |
| 控制台 | `.theme-xai` 深色 + 1px hairline + 零阴影 + 白 pill | 冷静、精密，但冷得让人不想久留；与落地页切换像换了一家公司 |
| 投递分析 | 曾有过纸感 + 珊瑚/青绿数据色（第三套） | 已被回滚为 xai，说明「局部另起一套」这条路走不通 |

三者共同缺陷：**低饱和、无重力、无记忆点**。截屏发给朋友，没有人能认出这是哪个产品。

### 1.2 目标语气

| 要 | 不要 |
| --- | --- |
| 轻松：像个懂行的朋友，不像 HR 系统 | 廉价：卡通、Emoji 堆砌、圆润到幼稚 |
| 吸睛：高饱和撞色 + 硬边重力，一眼有辨识度 | 喧闹：整屏彩色、每张卡都在喊 |
| 可信：能托住简历、数据与金钱（积分） | 冷淡：精密但没有体温的深色工作台 |

---

## 2. 三条原则

**P1 · 纸是底色，墨是骨架，撞色是标点。**
面积配比 ≈ 90 : 8 : 2。奶油纸占绝大多数，墨色负责结构（文字、描边），高饱和色只在「需要被看见的一瞬间」出现——主操作、当前状态、关键数字。

**P2 · 物理感来自硬阴影，不是模糊阴影。**
本项目**全面禁用 `box-shadow` 的模糊值**。所有可点击物用实心墨色偏移投影（`4px 4px 0 #171310`）表达「厚度」，悬停抬升、按下陷入。这既是识别度来源，也是可学习的心智模型：**有影子的东西可以按。**

**P3 · 两档密度，一套令牌。**
落地页可以尽情铺张，工作台必须克制。但克制的手段是**降低密度等级**，不是另起一套配色。全局只有一个 token 集，`Loud` / `Calm` 只调边框粗细、阴影档位、字号与装饰额度（详见 §3）。

---

## 3. 双密度架构

这是本系统最重要的结构性决策。工作台里有 KPI 卡、漏斗图、30 行岗位列表——把落地页的硬阴影照搬进来会变成视觉噪音；反过来把工作台的灰细线搬到落地页，则毫无冲击力。

### 3.1 两档定义

| 维度 | **Loud（响）** | **Calm（静）** |
| --- | --- | --- |
| 适用 | 落地页、登录/注册、空状态、引导、弹窗、CTA 区 | 控制台外壳、列表、表格、编辑器、数据面板 |
| 边框 | `2px solid var(--ink)` | `1px solid var(--line)`（`#E2D9C6`，仅装饰）；表单控件用 `--line-strong` |
| 阴影 | `4px / 8px` 实心墨偏移 | 无（hover 时 `2px 2px 0`） |
| 圆角 | 16 / 20 / 999 px | 10 / 12 px |
| 标题字重 | 700–800，负字距 | 600，负字距减半 |
| 纹理 | 点阵纸纹 + 胶带 + 贴纸（≤2 种/屏） | 无纹理，仅色阶分层 |
| 撞色占比 | 可达 10% | ≤ 3%，只给主操作与选中态 |
| 动效 | 入场编排 + 悬停抬升 + 装饰性微动 | 仅 120ms 颜色/位移过渡 |

### 3.2 切换方式

不使用新的主题作用域，改为**在容器上加 `data-density`**：

```html
<section data-density="loud">  <!-- 落地页区块 -->
<main data-density="calm">     <!-- 控制台主区 -->
```

CSS 侧由 `[data-density="calm"]` 覆写 `--edge-w` / `--shadow-card` / `--radius-card` 等**派生变量**，组件本身不需要知道自己在哪一档：

```css
:root              { --edge-w: 2px; --shadow-card: 4px 4px 0 var(--ink); --radius-card: 16px; }
[data-density="calm"] { --edge-w: 1px; --shadow-card: none;              --radius-card: 12px; }
```

好处：同一套 `Button` / `Card` 组件在两种密度下自动成立，无需 `variant="calm"` 这类分支。

### 3.3 产出态豁免（硬约束）

简历预览、PDF 导出、打印属于**产出态**，它的排版契约是「A4 纸上的正式文档」，不是「产品界面」。

- 禁止 `.resume-preview` / `.resume-markdown-preview` / `@media print` 内继承 `--ink` / `--paper` / 任何装饰。
- 现有 `markdownVariants.ts` 的 9 套版式与间距口径（`lineUnit = lineHeight × baseFontSize`）保持不动。
- 落地时给 `frontend/tests/` 增加回归断言：预览根节点计算样式不得出现 `Bricolage` / `#FF6A1F` / 硬阴影。

> 理由：用户把简历投给 HR。产品可以好玩，交付物必须端庄。

## 4. 色彩

### 4.1 令牌

对比度为**实测值**（WCAG 相对亮度公式），非估值。

| Token | Hex | 角色 | 纸底 `#FBF6EA` | 卡片 `#FFFDF8` |
| --- | --- | --- | --- | --- |
| `--paper` | `#FBF6EA` | 画布（奶油纸） | — | — |
| `--paper-2` | `#F3ECDC` | 凹陷区（侧栏、表头、代码块） | — | — |
| `--card` | `#FFFDF8` | 卡片/面板 | — | — |
| `--ink` | `#171310` | 正文、描边、硬阴影 | 17.1 : 1 | 18.2 : 1 |
| `--ink-2` | `#4B423A` | 次级正文 | 9.1 : 1 | 9.6 : 1 |
| `--ink-3` | `#75695C` | 弱化信息（时间戳、辅助说明） | 5.0 : 1 | 5.3 : 1 |
| `--line` | `#E2D9C6` | 装饰性分隔线（非控件边界） | 1.3 : 1 ⚠ 仅装饰 | — |
| `--line-strong` | `#9C8B71` | **控件边界**（输入框、下拉、复选） | 3.1 : 1 ✓ | 3.3 : 1 ✓ |
| `--cobalt` | `#2B3AFF` | **信号色**：主操作、链接、选中、数据强调 | 6.2 : 1 | 6.5 : 1 |
| `--cobalt-deep` | `#1A26C9` | 信号色 hover / 按下 | 9.0 : 1 | — |
| `--tangerine` | `#FF6A1F` | **撞色**：贴纸、徽章、装饰块（仅作填充） | 2.7 : 1 ⚠ 只填不写 | — |
| `--mint` | `#B9F2CE` | 成功态填充 / 「已匹配」 | 14.7 : 1（墨字） | — |
| `--butter` | `#FFE27A` | 高亮标记 / 提示条 | 14.4 : 1（墨字） | — |
| `--blush` | `#FFD7D3` | 危险态填充 / 「缺失」 | 14.0 : 1（墨字） | — |
| `--green` | `#1F8A57` | 成功**图形**（图标、圆点、柱） | 4.0 : 1 ✓（≥3 即可） | 4.3 : 1 |
| `--green-text` | `#146B41` | 成功**文字**（「+12」「↑33%」） | 6.1 : 1 | 6.4 : 1 |
| `--amber-text` | `#8A5300` | 待处理**文字** | 5.9 : 1 | 6.2 : 1 |
| `--danger` | `#B42318` | 错误文字 / 破坏性操作 | 6.3 : 1 | 6.5 : 1 |

### 4.2 两条硬规则（由实测倒推）

**规则 A · 语义颜色分「填充态」与「文字态」。**
同一个语义（成功）需要两个值：`--green` 只画图形（圆点、图标、柱状），`--green-text` 才允许上小字。原因是 `#1F8A57` 在卡片上只有 4.3:1，用于 11px 文字不达 AA。待处理同理（`--amber-text`）。

**规则 B · 控件边界必须 ≥ 3:1，装饰线不必。**
`--line`（1.3:1）只做卡片间分隔这类纯装饰；输入框、下拉、复选框的边框一律用 `--line-strong`（3.1:1），否则表单在低视力用户眼里是「无边界」的。这是一次真实的取舍：输入框会看起来重一点，但可辨认优先。

### 4.3 使用规则

1. 单屏（首屏可视区）`--cobalt` 强调元素 ≤ 3 处；CTA 有且仅有一个真主按钮。
2. 状态色只用于「状态」，不用于装饰。绿色只表示成功/已匹配，不表示「好看」。
3. 数据可视化序列：`cobalt → tangerine → --green → --ink-3 → butter`。
4. 禁止渐变用于大面积背景。允许的唯一渐变是「荧光标记」`linear-gradient(transparent 42%, var(--butter) 42%, var(--butter) 92%, transparent 92%)`。
5. `--tangerine` 与奶油纸对比度仅 2.7:1，**永远不与纸色文字搭配**：它只做填充块，上面压墨色文字，或作为纯装饰色块/圆点。

### 4.4 深色模式（Phase 5）

深色不是把颜色反过来，而是把「纸」换成「墨版纸」。令牌已定义，落地排期在最后：

```css
html.dark {
  --paper: #14110E;  --paper-2: #1C1814;  --card: #1F1A15;
  --ink: #FBF6EA;    --ink-2: #C9BFAF;    --ink-3: #9A8F80;
  --line: #2E2822;   --line-strong: #5A5148;
  --cobalt: #7C86FF;   /* 提亮以维持 4.5:1 */
  --tangerine: #FF7A38;
  --green-text: #5FD79B; --amber-text: #E8B44F; --danger: #FF8C82;
  --shadow-color: #000; /* 深色下硬阴影改纯黑，避免白色投影发光 */
}
```

硬阴影在深色下由 `var(--shadow-color)` 驱动，避免出现「白边发光」的廉价感。深色下的对比度须重新实测后再进入 Phase 5 验收。

## 5. 字体

### 5.1 角色分配

| 角色 | 字体 | 理由 |
| --- | --- | --- |
| Display | **Bricolage Grotesque**（500–800，variable） | 有轻微「不规矩」的字形（`a`/`g` 的错位），天然轻松；粗字重下极强海报感 |
| Body / UI | **Instrument Sans**（400–600） | 中性但不冷淡，x-height 高，小字号可读性好 |
| Mono | **DM Mono**（400–500） | 圆润的等宽，用于 eyebrow、数字、键盘提示；比 Geist Mono 更有体温 |
| 中文 | `PingFang SC` / `Noto Sans SC` / `Microsoft YaHei` | 中文无同级 Display 可用，靠**字重 + 负字距**承担语气 |

```css
--font-display: "Bricolage Grotesque", "PingFang SC", "Noto Sans SC", sans-serif;
--font-body:    "Instrument Sans", "PingFang SC", "Noto Sans SC", sans-serif;
--font-mono:    "DM Mono", "SFMono-Regular", ui-monospace, monospace;
```

> 中文标题（≥32px）取 `font-weight: 700; letter-spacing: -0.02em`；拉丁标题 `-0.035em`。中英混排时英文的负字距不可套用到中文（会挤压笔画），故用 `:lang(zh)` 单独降档。

### 5.2 字号阶梯

| 名称 | 尺寸 | 行高 | 字重 | 用法 |
| --- | --- | --- | --- | --- |
| poster | `clamp(44px, 6.2vw, 88px)` | 0.96 | 800 | 落地页 H1 |
| display | `clamp(32px, 3.6vw, 48px)` | 1.02 | 700 | 区块标题 |
| h3 | 24px | 1.15 | 700 | 卡片标题 |
| h4 | 19px | 1.3 | 600 | 小节标题 |
| body-l | 17px | 1.65 | 400 | 落地页正文 |
| body | 15px | 1.6 | 400 | 默认正文 |
| ui | 13.5px | 1.45 | 500 | 控制台行文字、按钮 |
| caption | 12px | 1.5 | 400 | 辅助说明 |
| eyebrow | 11px / `0.1em` / uppercase / mono | 1.2 | 500 | 分组标签、KPI 名 |

### 5.3 排版细则

- 正文最大行宽 `68ch`；落地页副标题 `52ch`。
- 数字统一 `font-variant-numeric: tabular-nums`（KPI、积分、日期），避免跳动。
- 中文段落 `text-wrap: pretty`；标题 `text-wrap: balance`。
- 标题内不相邻的两个标点不换行：`word-break: keep-all` 用于中文短标题。

## 6. 形状与重力

### 6.1 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r-chip` | 999px | 标签、pill 按钮 |
| `--r-input` | 12px | 输入框、下拉 |
| `--r-card` | 16px（Calm 12px） | 卡片、岗位卡 |
| `--r-panel` | 20px（Calm 14px） | 大面板、弹窗 |
| `--r-sticker` | 4px | 贴纸、票根（故意不圆，制造纸感） |

### 6.2 描边与阴影

```css
--edge: var(--edge-w) solid var(--ink);

--shadow-chip:  2px 2px 0 var(--shadow-color);   /* chip、小按钮 */
--shadow-card:  4px 4px 0 var(--shadow-color);   /* 卡片、按钮 */
--shadow-hero:  8px 8px 0 var(--shadow-color);   /* 首屏大面板、弹窗 */
--shadow-soft:  0 1px 2px rgb(23 19 16 / .05);   /* 仅 Calm 档浮层（下拉、toast） */
```

**禁止**任何 `blur` 值 > 2px 的阴影。`--shadow-soft` 是唯一的例外，且仅限浮层。

### 6.3 交互物理（签名动效）

| 状态 | 变换 | 阴影 |
| --- | --- | --- |
| resting | `translate(0,0)` | `4px 4px 0` |
| hover | `translate(-2px,-2px)` | `6px 6px 0` |
| active | `translate(2px,2px)` | `0 0 0` |
| disabled | `translate(0,0)`，`opacity: .45` | `4px 4px 0`（保留厚度，表达「还在但不给按」） |

```css
.btn { box-shadow: 4px 4px 0 var(--shadow-color); transition: transform .12s var(--ease-pop), box-shadow .12s var(--ease-pop); }
.btn:hover  { transform: translate(-2px,-2px); box-shadow: 6px 6px 0 var(--shadow-color); }
.btn:active { transform: translate(2px,2px);   box-shadow: 0 0 0 var(--shadow-color); }
```

这一条在**全站所有可点击元素**上一致执行（按钮、卡片、Tab、菜单项、上传区）。它是本设计系统的「手感」。

## 7. 空间

- 基线 **4px**；允许的间距值：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72 / 96 / 128。
- 容器：`max-width: 1180px`，gutter `32px`（移动端 20px）。
- 区块纵向节奏：移动 `72px`，桌面 `112px`；Loud 档允许 `128px` 制造呼吸。
- Calm 档内容区 padding：`28px 32px`；卡片内 padding：`20px`；行高 `44px`。
- 栅格：12 列，`gap: 24px`。允许并鼓励**跨列不对称**（如 7/5、8/4），但每屏只允许一处打破栅格。

## 8. 纹理与装饰

| 元素 | 规格 | 额度 |
| --- | --- | --- |
| 点阵纸纹 | `radial-gradient(var(--ink) 1px, transparent 1px) 0 0/22px 22px`，`opacity: .055` | 仅 Loud 档背景 |
| 胶带 | `rgba(255,226,122,.72)`，28×96px，`rotate(-4deg)`，左右各一 | 首屏截图框 |
| 贴纸 | `--r-sticker` + `--edge` + `--shadow-chip` + `rotate(-3deg)` | 每屏 ≤2 |
| 荧光标记 | 见 §4.2 唯一允许渐变，覆盖文字下 50% 高度 | 落地页标题关键词 |
| 编号徽章 | 24px 圆 + cobalt 填充 + 墨描边 + 硬阴影 | 步骤/流程 |
| 票根缺口 | `mask-image` 双圆切角，用于「积分/额度」卡 | 每屏 ≤1 |

**一屏最多两种装饰。** 装饰是标点，不是正文。

## 9. 动效

### 9.1 曲线与时长

```css
--ease-pop: cubic-bezier(.2,.9,.25,1.15);  /* 轻微过冲，用于位移/缩放 */
--ease-out: cubic-bezier(.22,1,.36,1);     /* 入场淡入 */
--dur-fast: 120ms;   /* 颜色、位移 */
--dur-base: 220ms;   /* 展开、切换 */
--dur-slow: 420ms;   /* 区块入场 */
```

### 9.2 编排

- **入场**：`opacity 0 → 1` + `translateY(14px) → 0`，同一父容器内子元素 `animation-delay` 步进 `60ms`，最多 6 个（第 7 个起合并到第 6 个延迟）。
- **滚动**：`IntersectionObserver`，`threshold: .15`，`once: true`。不使用滚动驱动动画（性能与可预期性）。
- **悬停**：只允许位移 + 阴影，不允许缩放 > 1.02。
- **装饰微动**：Ticker 横向滚动 26s 线性；贴纸 `rotate(-3deg → -1.5deg)` 6s 往复。均需 `prefers-reduced-motion` 关闭。
- 禁止：视差、鼠标跟随光斑、无限旋转的 loading 图形（用 3 点脉冲代替）。

### 9.3 降级

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .01ms !important; transition-duration: .01ms !important; }
}
```

## 10. 组件规范

### 10.1 Button

| 变体 | 填充 | 文字 | 描边 | 阴影 | 用途 |
| --- | --- | --- | --- | --- | --- |
| primary | `--cobalt` | `--paper` | `2px --ink` | `4px` | 每屏一个主操作 |
| secondary | `--paper` | `--ink` | `2px --ink` | `4px` | 并列操作 |
| ghost | 透明 | `--ink-2` | 无 | 无 | 工具栏、行内操作 |
| danger | `--blush` | `--ink` | `2px --ink` | `4px` | 删除、放弃投递 |
| link | 透明 | `--cobalt` | 无 | 无 | 文字链（下划线 2px，offset 3px） |

尺寸：`sm` 32px / `md` 42px / `lg` 52px；水平 padding 14 / 20 / 28px；圆角 `--r-chip`。
图标与文字间距 8px；图标 16/18/20px，`stroke-width: 2`。
加载态：文字换成 3 点脉冲，宽度不变（避免布局跳动）。

### 10.2 Chip / Badge

- 高度 26px，`--r-chip`，`1px --ink`，`mono 11px`，`letter-spacing .06em`，大写。
- 状态色只染填充：`mint`（匹配）/ `butter`（待处理）/ `blush`（缺失）/ `paper-2`（中性）。
- 岗位阶段徽章：左侧 7px 圆点 + 标签，圆点取状态色，标签永为墨色文字。

### 10.3 Card / Panel

```
Calm  ：1px --line + --card 填充 + --r-card(12) + 无阴影
Loud  ：2px --ink + --card 填充 + --r-card(16) + --shadow-card
Hover（仅可点击卡片）：translate(-2px,-2px) + --shadow-card
```
卡片标题 15px/600；正文 13.5px `--ink-2`；元信息 12px `--ink-3`。

### 10.4 Input

- 高度 42px，`1px --line-strong` → focus 时 `2px --cobalt` + `0 0 0 3px rgb(43 58 255 / .16)`。
- 标签在上方 12px/500；帮助文案在下方 12px `--ink-3`；错误态描边 `#D92D20` + blush 底。
- 错误用**文字 + 图标**双重表达，不单靠颜色。

### 10.5 Tabs

- Calm：底部 2px 墨色指示条，激活项 600 字重，未激活 `--ink-3`。
- Loud：胶囊容器 `--paper-2` + 内嵌白 pill + 硬阴影。

### 10.6 表格 / 列表行

- 行高 44px，行间 `1px --line`，无斑马纹。
- 悬停整行 `--paper-2`；选中整行左侧 3px cobalt 竖条。
- 数值列右对齐 + tabular-nums。

### 10.7 KPI

- 结构：eyebrow（mono 11px）→ 数值（32px/700/tabular）→ 变化量（12px，箭头 + 语义色）。
- Calm 档：白卡 + 1px 线；Loud 档允许 one-of 卡片用 `--butter` 或 `--mint` 填充 + 硬阴影（首屏最多 1 张）。

### 10.8 Empty State

- 允许 Loud 档：虚线 2px 圆圈 + 贴纸 + 一句轻松的话 + 一个 primary 按钮。
- 文案语气：说「现在可以做什么」，不说「暂无数据」。

### 10.9 Toast

- 右下角堆叠，`--r-card`，白底，2px 墨描边，`--shadow-card`；左侧 4px 状态色竖条。4s 自动消失。

### 10.10 Nav / Sidebar

- 落地页顶栏：透明 → 滚动后 `--paper/92 + blur(8px)` + 底部 1px 线。Logo 左侧，导航居中，CTA 右侧。
- 控制台侧栏：`--paper-2` 底，`1px --line` 右边；菜单项 `--r-chip`，激活态 **cobalt 填充 + paper 文字 + 硬阴影 2px**，未激活 `--ink-2` + hover `--paper`。
- 保留现有折叠行为与 228px 宽度。

### 10.11 Progress / 漏斗

- 进度条：底 `--paper-2`，填充 `--cobalt`，高 6px，`--r-chip`；进行中加 4px 右端「墨色端点」。
- 漏斗层级用**同一色相不同明度**（cobalt 100/72/48%），不换色相。

## 11. 页面级应用

| 页面 | 密度 | 关键决策 |
| --- | --- | --- |
| 落地页 `/zh` | Loud | H1 海报级；首屏截图框胶带 + 硬阴影；文案关键词上荧光标记；底部 CTA 用 cobalt 大色块 + 票根缺口 |
| 登录 / 注册 `/login` | Loud | 左品牌海报 + 右 340px 表单卡（见 §11.2）；备案号悬挂在卡片下方 |
| 控制台首页 | Calm + 1 处 Loud | KPI 行 Calm；「继续上次投递」卡用 butter 填充（全屏唯一 Loud） |
| 岗位卡 `/jobs` | Calm | 两栏列表 + 详情；阶段徽章圆点编码；空列用 Loud 虚线空状态 |
| 投递分析 | Calm | 图表用 cobalt 单色阶 + tangerine 对照；KPI 去装饰 |
| 简历工作台 `/workbench/[id]` | Calm | 三栏可拖拽、默认 20/32/48（见 §11.1）；`.tiptap` 排版规则**不变** |
| 简历预览 / PDF | 豁免 | 见 §3.3；纸张纯白、严格 A4 比例 |

### 11.1 简历工作台（三栏）

| 区域 | 现状尺寸 | 密度 | 要点 |
| --- | --- | --- | --- |
| 顶栏 | 64px 高 | Calm | 返回 / 标题 + 保存状态 / 撤销重做 / 校对 / 导出 PDF；全屏唯一填充色按钮是「导出」 |
| 设置栏 | 默认 20%（可拖拽、可折叠） | Calm | 分组小标题 10.5px/600 正文体，**不用 mono 大写**（`letter-spacing` 会把汉字拉散） |
| 编辑区 | 默认 32%（可拖拽） | Calm | 工具条控件 27–28px、间隔 2px；正文 14px / 行高 1.75 |
| 预览区 | 默认 48%（可拖拽、可收起） | **豁免** | 纸张 `aspect-ratio: 210/297`，白底 + 极淡投影；不参与改版 |

四条硬规则：

1. **工作台内禁止硬阴影**。`[data-density="calm"]` 已把 `--shadow-card` 置为 `none`，按钮统一用 `.btn--calm`（1px 边、无阴影、hover 只换底色）。
2. **三栏按百分比分配、可拖拽，并记住用户上次的宽度**（`LAYOUT_CONFIG.DEFAULT = [20, 32, 48]`）。不要为了「纸张尺寸恒定」把宽度改回写死——纸张由 `aspect-ratio` 自适应，用户对导出效果的判断以 PDF 为准，不由实时预览宽度决定。
3. **编辑区与预览区各自独立滚动**。预览收起时由 `PreviewDock`（`fixed` 悬浮入口）承担展开与导出，它只是**折叠态的触发器**，不是常驻悬浮预览层；展开态编辑区占满 100%，不再给 dock 预留占位。
4. **纸张永远是纯白 `#FFF`**，不用 `--card`（`#FFFDF8` 偏黄）。奶油底是界面语言，白纸是打印契约，两者不能混。

> 三套预设布局已存在，改版时保留：`DEFAULT [20,32,48]` / `SIDE_COLLAPSED [50,50]` / `EDIT_FOCUSED [20,80]` / `PREVIEW_FOCUSED [20,80]`。它们与双密度不冲突——密度改的是描边与阴影，不改布局比例。

> 已知取舍：左右配对容器（`:::left … ::: :::right … :::`）在编辑器内显示为**上下两段**，因为 ProseMirror 文档模型没有「同行双列」节点。预览与导出仍是左右对齐。已在样张的「已知取舍」卡片中显式标注。

### 11.2 登录 / 注册

放弃「居中单卡」，改为左右分栏（`1.06fr / .94fr`，最小高度 596px）：

| 位置 | 内容 | 规则 |
| --- | --- | --- |
| 左栏 | 品牌锁定 + 海报级主张 + 三条承诺 | 主张 ≥32px / 行高 1.06；承诺用 `--mint` 序号圆点；右下角**唯一**装饰贴纸 `rotate(-4deg)` |
| 右栏 | 340px 表单卡 | 登录 / 注册用 segmented 切换，不跳路由；卡片是全页唯一硬阴影对象 |
| 卡片下方 | ICP 备案号 + 版权 | 11.5px，链接工信部备案系统；**不得**弱化到 10px 以下，也不塞进卡片内容区 |

状态处理：

- **失败**用内联红条（`--blush` 底 + `--danger` 字），不用只靠 toast——表单内的红字会被忽略，但纯 toast 也会被划走，两者都要。
- **限流**只由按钮承载倒计时（「42 秒后可重试」），不再叠一条黄色提示条：同一件事说两遍会稀释信号。
- **禁用主按钮**用中性灰（`--paper-2` 底 + `--ink-3` 字 + `--line-strong` 边），不要用 45% 透明的主色——钴蓝降到 45% 在奶油纸上会发紫，显得像坏掉的控件。

**注册码降权（机制保留，但不做卖点）**：

注册码是准入机制，不是产品卖点。它的视觉与文案权重必须降到「用户需要它的那一刻才出现」。

| 规则 | 说明 |
| --- | --- |
| 允许出现的位置 | ① 注册表单里的 `注册码` 字段（用户名、密码之后）② 该字段下方一行小字「没有注册码？点此领取」。**仅此两处** |
| 禁止出现的位置 | 跑马灯、hero 证明条、票根主题与格位、CTA 带、贴纸、页脚导航、登录页三条承诺 |
| 禁止的措辞 | 「每日限量」「名额」「倒计时」「重置时间」「Daily Drop」「即开」等稀缺/促销词；不得为注册码单独开模块、贴纸或任何视觉焦点 |
| 字段样式 | 与用户名、密码完全同规格（同高、同字号、同标签样式），不描边加重、不加高亮、不置顶 |
| 卖点位替代 | 改说确定的产品事实：注册即送 50 积分 / 按次计费无订阅 / PDF 导出免费 / 简历仅自己可见 |
| 积分票根 | 四格只放价格与规则（匹配 5 / 话术 1 / 不过期 / 导出免费），不放「名额」「重置时间」 |

> 理由：注册码原本是内测期的临时机制，但在旧稿里被做成主题（跑马灯 ×2、hero 证明条、票根眉标与两格、CTA 小字、登录承诺、贴纸，合计 9 处）。后果有两个：一是整站语气从「轻松」滑向「抢票」，与 §2 的「轻松 · 可信」冲突；二是与「注册即送 50 积分」并列时读起来像「先抢码才有积分」，反而抬高了进入门槛。降权后它只是注册表单的第三个格子，用户不需要提前知道它。

## 12. 可及性

| 检查项 | 要求 | 本方案状态 |
| --- | --- | --- |
| 正文对比度 | ≥ 4.5:1 | `--ink` 17.1 / `--ink-2` 9.1 / `--ink-3` 5.0 ✓ |
| 控件边界对比度 | ≥ 3:1 | 表单用 `--line-strong` 3.1 ✓（`--line` 仅装饰，不用于控件） |
| 语义色文字 | ≥ 4.5:1 | 文字一律用 `--green-text` 6.4 / `--amber-text` 6.2 / `--danger` 6.5 ✓ |
| 焦点可见 | 3px 环 + 2px offset，聚焦环与背景对比 ≥ 3:1 | `--cobalt` 6.2 / `--ink` 17.1 ✓ |
| 触达尺寸 | ≥ 40×40px（移动端 44） | 按钮 md 42 / 行 44 ✓ |
| 不单靠颜色 | 状态需文字或图标冗余 | 徽章带标签、错误带文案 ✓ |
| 动效 | `prefers-reduced-motion` 全量降级 | ✓ |
| 语义 | 保留现有 `<main>` / `<nav>` / `<header>` 地标 | ✓ |

**已知例外（显式接受）**：`--tangerine` 仅作填充，其上文字为 `--ink`（6.45:1）符合要求；但它本身不得作为任何文字色。`--green`（4.3:1）只允许出现在图标、圆点、柱状图等非文本元素上。

> 上表数值由脚本按 WCAG 2.1 相对亮度公式实测得出，评审稿修订过程中据此修正过两个原始取值（`--ink-3` 由 `#8A7F72` 3.6:1 改为 `#75695C` 5.0:1；新增 `--green-text` 替代直接用 `--green` 上字）。落地后应在 `frontend/tests/` 增加令牌对比度断言，防止后续被静默改浅。

## 13. 落地路径

### Phase 0 — 令牌（0.5 天，风险低）
- `globals.css`：新增 `:root` 令牌（§4/§5/§6），**含 `--line-strong` / `--green-text` / `--amber-text` / `--shadow-color`**；保留旧变量别名，确保旧组件不崩。
- `tailwind.config.ts`：扩展 `colors.paper/ink/cobalt/tangerine/mint/butter/blush`、`fontFamily.display/body/mono`、`boxShadow.punch*`。
- 新增 `frontend/tests/design-tokens.test.ts`：断言 §12 表中每个文字色与其背景的对比度 ≥ 阈值（防止后续被改浅）。
- 产出：无视觉变化，但 `bg-paper` 等类名可用。

### Phase 1 — 原语（1 天）
- 重写 `components/ui/button.tsx`、`card.tsx`、`input.tsx`、`badge.tsx`、`tabs.tsx` 的样式层（不改 API）。
- 落地 §6.3 交互物理为 `.punch-press` 工具类。
- 产出：全站按钮/输入框瞬间统一。

### Phase 2 — 落地页（1.5 天）
- `HeroSection` / `FeaturesSection` / `CTASection` / `Footer` / `LandingHeader` 按 Loud 重排。
- 保留现有 `AnimatedFeature` 与 AutoSlide 逻辑，仅替换样式与结构。
- 首屏 LCP 图片策略（AVIF/WebP 三级回退）**不得改动**。

### Phase 3 — 控制台外壳（1 天）
- `.theme-xai` 收敛为 `.theme-punch`（保留旧名作别名一个版本）。
- `Sidebar` / 顶栏 / 用户菜单按 Calm 重绘；移除深色专用色板，改为 `data-density`。

### Phase 4 — 密集面（1.5 天）
- 岗位卡、分析页、简历列表、编辑器工具栏。
- 图表 `tokens.ts` 改为读新令牌。

### Phase 5 — 深色（1 天，可延后）
- §4.3 令牌 + 硬阴影 `--shadow-color` 切换 + 对比度复测。

### 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 硬阴影在密集列表产生噪音 | 双密度机制 + Calm 档禁用阴影 |
| 中文字体回退导致标题气质塌陷 | 中文单独降字距/提字重，附 A/B 截图验收 |
| 撞色影响可读性 | 令牌级限制（§4.2）+ 评审冻结 |
| 改 `.theme-xai` 波及 portaled 组件 | 保留 `theme-xai` 别名；`DropdownMenu`/`Dialog` 的 `className="theme-xai"` 不改 |
| 预览被污染 | §3.3 回归测试前置 |
