# JDMatch 2.0 交互设计稿

本目录存放 2.0「简历匹配对话式入口」的交互设计稿，以独立 HTML 文件呈现（浏览器可直接打开查看）。

设计语言统一遵循项目 `docs/DESIGN.md` 的 **Paper & Punch** 规范：奶油纸 `#fbf6ea`、硬墨 `#171310`、钴蓝 `#2b3aff`、撞色黄油 `#ffe27a`、硬阴影。

## 最终方案（本目录）

| 文件 | 内容 | 对应规划章节 |
|---|---|---|
| `05_简历匹配对话式入口页.html` | 简历匹配菜单改造后的对话式入口页：左侧会话列表 + 右侧对话流（预设语句 + SSE 流式 + 匹配结果卡） | PLAN_conversation_memory.md §2B/§4 |
| `06_匹配进度 SSE 事件流.html` | 匹配不流式文本、但走进度事件的 SSE 阶段展示（解析 JD → 分析匹配度 → 优化简历） | §5 SSE 流式 |
| `07_左侧固定菜单与对话历史.html` | 左侧「固定菜单（4 项不变）+ 对话历史区块（新增）」结构 | §4.2 入口改造 |
