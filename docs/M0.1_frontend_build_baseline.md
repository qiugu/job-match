# M0.1 前端构建基线验收

日期：2026-09-26

## 目标

恢复 TanStack Start 前端的可重复类型检查、测试和生产构建，避免未参与正式路由的旧 Next 目录阻塞发布检查。

## 修改范围

- `frontend/tsconfig.json`：类型检查入口收窄到 `src/routes`、路由注册和 Vite 类型；补齐 ES2022 与 `baseUrl`。
- `frontend/vite.config.ts`、`frontend/vitest.config.ts`：增加明确的 `@` 源码别名，并允许路径插件处理实际被 Vite 加载的文件。
- `frontend/src/vite-env.d.ts`：补齐 `mark.js`、File System Access API 和 Vite 环境类型。
- 修复正式入口图中的 admin ECharts、编辑器可选值、移动端 props、旧 JSX 属性、日期组件和少量组件类型问题。
- `frontend/src/routes/app/dashboard/settings.tsx` 重命名为 `-settings.tsx`，明确其为停用的非路由文件，消除构建扫描警告。

## 验收结果

```text
pnpm exec tsc --noEmit --pretty false   PASS

```

## 边界

本次只恢复正式 TanStack Start 入口图的类型检查，不把未被路由引用的历史 Next 文件重新纳入发布门禁。后续若删除旧目录，应单独验证其是否仍被业务或脚本引用。
