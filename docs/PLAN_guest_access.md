## 1. 现状盘点

| 功能 | 现状 | 依赖资源 |
| --- | --- | --- |
| 营销落地页（`/$locale`） | 公开，SEO 可索引 | 纯静态 |
| 模板预览（`/app/preview-template/$id`） | **需登录**，且继承 `/app` 的 `noindex` | 纯前端渲染（iframe 模板渲染器） |
| 简历编辑器（workbench） | 需登录 | 编辑纯客户端；**保存依赖后端** `master_resumes` |
| 实时预览 / 排版设置 | 需登录 | 纯客户端 |
| PDF 导出 | 需登录（免费、不扣积分，限流 20/小时） | **服务端无头渲染** |
| JD 匹配（5 积分）/ 求职信（1 积分） | 需登录 | **LLM 调用** |
| AI 润色 / 语法检查 / 简历导入解析 / 翻译 | 需登录 | **LLM 调用** |
| 岗位卡 / 投递统计 / 数据分析 | 需登录 | 后端数据 |
| 登录 / 注册 | 公开 | 注册即送 50 积分（注册码可选） |

关键架构事实：

- 前端 `useResumeStore` 已是「内存工作副本 + 后端唯一数据源」模式，本地 persist 已移除（2026-08-29 起）。
- 编辑器渲染、模板引擎、排版设置全部在客户端完成，**不碰服务器**。
- 后端接口统一走 `get_current_user`，无匿名通道。

## 2. 规划原则（社区最佳实践）

参照 FlowCV / Rezi / Resume.io / Canva / Figma 等 freemium 工具的共识做法：

1. **价值前置，成本后置**：让用户先体验到核心价值（编辑 + 预览），把「付费级成本」（LLM、服务端渲染、云存储）留在登录墙内。
2. **登录即转化触发器（value moment）**：登录墙应设在用户「最想要结果」的一刻——导出 PDF、AI 匹配、云端保存——而非进门时。
3. **游客数据不静默丢失**：游客产物必须有明确的生命周期说明（本地暂存）和登录后的承接路径（一键转入账号），否则试用体验反噬口碑。
4. **游客态零信任**：任何游客可达的服务端能力都要按滥用最坏情况设计限流；本方案中游客态**不新增任何服务端业务接口**。
5. **SEO 与工具页分离**：游客可访问的「内容型」页面（模板展示）应可索引；「操作型」页面（编辑器）保持 noindex。

## 3. 功能开放矩阵（结论）

| 功能 | 游客 | 登录用户 | 判定依据 |
| --- | :-: | :-: | --- |
| 营销落地页 | ✅（现状） | ✅ | 静态零成本 |
| **模板画廊 + 模板预览页** | ✅ **新开放** | ✅ | 纯客户端渲染，零边际成本；兼做 SEO 获客入口 |
| **简历编辑器（全部模板、结构化 + Markdown、排版设置、实时预览）** | ✅ **新开放（本地暂存）** | ✅ | 核心价值前置；纯客户端；成本为零 |
| 未登录草稿恢复（localStorage） | ✅ **新开放** | — | 防数据丢失红线 |
| 登录后「导入游客草稿」 | ✅ **新开放** | — | 转化承接 |
| PDF 导出 | ❌ 点击→引导登录 | ✅ 免费 | 服务端无头渲染有真实成本；登录是标准转化触发器（见 §5 备选方案） |
| JD 匹配 / 求职信 / AI 润色 / 语法检查 / 导入解析 / 翻译 | ❌ 点击→引导登录 | ✅ 积分制 | LLM 成本 + 积分账户必须实名（账号）归属 |
| 云端简历列表 / 历史版本 | ❌ | ✅ | 服务端存储 |
| 岗位卡 / 投递统计 / 数据分析 / 设置 / 管理后台 | ❌ | ✅ | 服务端数据 + 权限 |

一句话结论：**「编辑与预览全部放开，凡是要花服务器钱、要归户记账的，全部留在登录墙内。」**

## 4. 游客编辑器方案（核心项）

### 4.1 体验设计

- 入口：落地页 CTA 由「立即登录」增加/改为「免费试用（无需注册）」，直达游客编辑器。
- 游客态全站顶部常驻轻量提示条：`游客模式 · 内容仅保存在本浏览器` + `登录保存到云端` 按钮（遵守全站禁支付话术规则，只讲事实）。
- 游客编辑器内，AI 类按钮与导出按钮**可见但带锁标识**；点击弹出登录引导（携带 `redirect` 回跳 + 上下文提示，如「登录后即可导出 PDF」），不隐藏功能——隐藏会削弱「登录后能获得什么」的预期。
- 刷新/关闭页面前若草稿有未保存变更，beforeunload 提示（仅游客态）。

### 4.2 数据模型

- 游客草稿存 `localStorage`（key 前缀 `jdmatch.guest.`），存 `ResumeData` 全量 JSON + 时间戳，单一活跃草稿，容量超限（约 >2MB）时提示改用登录。
- `useResumeStore` 增加持久化策略开关：`cloud`（现状）/ `guest-local`。游客态走 `guest-local`：
  - 保存动作 = 写 localStorage，无网络请求；
  - `syncedIds` 语义在游客态映射为「已本地保存」。
- **登录后承接**：登录成功且检测到本地游客草稿时，弹「检测到未保存的本地简历，是否导入到云端？」——确认即创建后端简历并把 localStorage 草稿写入，导入成功后清除本地副本；拒绝则保留本地副本（用户可在游客态继续）。
- 游客草稿与登录用户的云端简历**永不混存**：`/app` 登录墙内不读 guest key，避免合并冲突。

### 4.3 路由与 SEO

- 新增公开路由（示意）：
  - `/templates`（模板画廊）与 `/templates/$id`（预览）——由 `/app/preview-template/$id` 迁出，改为可索引（保留落地页级 meta/结构化数据）。
  - `/edit`（游客编辑器）——`noindex,nofollow`（操作型动态页面，索引无意义且内容稀薄）。
- `/app` 登录墙维持不变；已登录用户访问 `/edit` 时重定向到 workbench（避免双入口分裂）。
- 迁移用 301/路由别名兼容旧 `/app/preview-template/$id` 外链。

## 5. PDF 导出的两个备选方案（需评审定夺）

| 方案 | 说明 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. 登录墙（推荐先行）** | 游客点击导出 → 登录引导，导出本身免费 | 零新增滥用面；登录是行业标准转化点；实现成本最低 | 少量游客在导出前流失 |
| B. 游客限次水印导出 | 游客可导出 1 次，带浅水印，IP 限流 | 试用闭环更完整，转化率理论上更高 | 新增匿名出口：需按 IP 限流、防脚本刷、水印溯源；导出质量争议风险 |

建议：先落地方案 A（与「PDF 导出免费」的注册转化叙事一致），上线后观察导出环节的登录转化漏斗，若数据不佳再实验方案 B。

## 6. 实施分期

| 阶段 | 内容 | 改动面 | 验收标准 |
| --- | --- | --- | --- |
| **P1 模板公开化** | `/templates` 画廊 + `/templates/$id` 预览迁出登录墙，SEO meta/JSON-LD，旧路径兼容 | 前端路由 + SEO 库 | 未登录可浏览全部模板；页面可索引；旧链接可达 |
| **P2 游客编辑器** | `/edit` 游客路由、`guest-local` 持久化策略、游客提示条、锁标识 + 登录引导（带 redirect 上下文） | 前端 store + 编辑器外壳 + i18n（zh/en 双写） | 未登录可完整编辑/预览/切模板；刷新后草稿恢复；AI/导出点击均正确弹登录引导 |
| **P3 登录承接** | 登录成功后检测并导入游客草稿；导入成功清理本地副本 | 前端登录流程 | 导入后云端可见同一份简历，本地副本清除；拒绝导入不破坏游客数据 |
| **P4（观察后决策）** | PDF 导出方案 B 实验（如做）：匿名限次 + 水印 + IP 限流 | 后端 export.py + 前端 | 限流生效；水印可见；不影响登录用户体验 |
| P5 文案与埋点 | 落地页/FAQ/登录页文案同步「无需注册即可试用」；转化漏斗埋点（游客进入→登录→导出） | i18n + telemetry | zh/en 文案一致；漏斗数据可观测 |

依赖与风险：

1. `useResumeStore` 持久化策略开关是 P2 最大改动面——涉及 `savedSnapshots`/`syncedIds`/自动保存路径，需按现有脏标记契约（I2 修复）补单测。
2. 游客态绝不调用任何后端业务接口——评审代码时以「游客态网络请求 = 0（登录/注册除外）」为红线检查项。
3. `localStorage` 容量与隐私模式（Safari 隐私窗会话级存储）需在文案中如实告知「本地保存」的局限。
4. 路由迁移注意 `/app` 的 `noindex` 继承逻辑：`/templates` 在墙外，不得误继承。

## 7. 成功指标

- 游客编辑器进入 → 登录注册转化率（北极星）。
- 模板画廊页 → 游客编辑器进入率。
- 登录引导弹层（AI/导出触发）→ 完成登录率。
- 登录后游客草稿导入率（承接体验是否顺畅的代理指标）。
