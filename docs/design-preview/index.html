08

请确认这 8 项

确认后进入 Phase 0（令牌层，零视觉变化），再逐阶段落地。

A 方向

接受奶油纸 + 硬墨 + 撞色的「轻松」，而不是柔和渐变 / 玻璃拟态的「轻」。

B 密度

接受落地页 Loud / 工作台 Calm 的分档，而不是全站同一种强度。

C 主色

信号色用电光钴蓝 #2B3AFF，橙色只做填充装饰。

D 字体

Display 用 Bricolage Grotesque，正文用 Instrument Sans，替换现有 Newsreader + Inter。

E 豁免

同意简历预览 / PDF 导出不参与本次改版，保持打印契约。

F 顺序

同意 Phase 0→5 排期：先令牌与原语，再落地页，最后控制台与深色。

G 工作台

接受设置 224 / 编辑自适应 / 预览 396 固定三栏；预览独立滚动、不加悬浮层，工具条全部 1px 无阴影。

H 登录形态

接受登录页从居中单卡改为「左品牌 + 右表单」分栏，备案号悬挂在卡片正下方。
